# Keybinds Reference

## Core

- Prefix: `Ctrl-a` (primary), `Ctrl-b` (secondary)
- Reload: `prefix r`
- New window (cwd): `prefix c`
- Rename window: `prefix ,`
- Rename session: `prefix $`

## Panes

- Split horizontal: `prefix |`
- Split vertical: `prefix -`
- Resize: `prefix h/j/k/l`
- Move focus: `prefix H/J/K/L`
- Zoom toggle: `prefix z`

## Workflows

- Popup shell: `prefix Enter`
- Popup lazygit: `prefix g`
- Smart finder/session helper: `prefix f`

## Copy Mode (Vi)

- Enter copy mode: `prefix [`
- Begin selection: `v`
- Yank selection: `y`
- Cancel: `Esc`

## Plugin Manager

- Install plugins: `prefix I`
- Update plugins: `prefix U`
- Clean removed plugins: `prefix M-u`
